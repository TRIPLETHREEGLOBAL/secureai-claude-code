# SecureAI for Claude Code

This repository contains the Claude Code adapter only. SecureAI Core is a separate proprietary product and is not included here.

**Development status:** This adapter has not yet been verified with a production SecureAI Core installer. The current Core package, customer download, and website checkout are not live. Do not rely on this plugin to provide protection until LightningFlow announces a compatible release.

The package currently contains a local MCP server, a session hook, and terminal proxy helpers. Their integration with the current Core interface is being corrected. Claude Desktop and Claude web or mobile sessions are not covered by this local Claude Code plugin.
